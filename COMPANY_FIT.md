# RapidAid-Network — Company and Team Fit

**Snapshot:** 2026-11-13

## Project thesis

A small simulation that chooses a nearby available response resource based on an incident location and a severity label.

Matches below are potential employer/skills fit, not known customers, users, partners, endorsements or hiring interest.

## Amazon Web Services

**Relevant public technical areas:** Geospatial services, scalable APIs and data engineering.

**Potential role families:** Software Engineer, Backend Engineer, Data Engineer, Applied AI Engineer, Geospatial Engineer or Research Engineer.

**Evidence this project should demonstrate:** JavaScript/Node.js prototype using Haversine distance and rule-based selection from supplied responder, support-point and ambulance records. It is not connected to emergency services and must not be used to dispatch real responders or determine medical priority.

# Agent Instructions — RapidAid-Network

Read README.md, CONTRIBUTING.md, FEATURE_UPGRADE_PLAN.md and ACTIVITY_LOG.md before making changes.

- Inspect code, tests, open issues and PRs before editing.
- Work on one bounded task on a feature branch.
- Add deterministic tests for normal, boundary and failure behavior.
- Treat sample data as sample; preserve source attribution and licensing.
- Never connect to real emergency services or make real hiring/medical decisions as part of this prototype.
- Run checks and report exact commands/results; never invent validation.
- Update docs and activity log; open a PR for human review.
- Do not merge, deploy or change repository settings autonomously.

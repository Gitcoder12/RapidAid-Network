# Agent Skills — RapidAid-Network

## Domain and data audit
Inspect record schemas, geographic/time fields, source provenance and domain assumptions.

## Input validation
Implement and test numeric ranges, enums, missing fields, malformed payloads and oversized inputs.

## Core behavior
Test deterministic selection/query results, tie-breaking and failure cases.

## Safety and privacy
Keep prototypes separate from real emergency/hiring systems; avoid collecting unnecessary personal data.

## Documentation
Explain user workflow first, then architecture, algorithms, assumptions, limitations and reproducibility.

Agents may prepare code and PRs but cannot merge or deploy. Human maintainer approval is required.
